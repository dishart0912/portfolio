Overview

About the Project

This is a personal Figma animation practice project — a product landing page concept for a donut brand. The focus was on experimenting with flavour-coded colour transitions, large-scale typographic layouts, and smooth Figma prototype interactions.

Each flavour — Blueberry, Green Apple, and Caramel — gets its own full-bleed background, with the donut floating over large masked typography. This was not a client project, but a design exploration focused on motion, layout, and visual storytelling.

Process

Design Process

Designed entirely in Figma. The main challenge was achieving the typographic masking effect — where the large flavour name sits behind the floating donut. This was done using Figma's layer ordering and component variants for each flavour state.

A purely visual experiment — focused on colour, motion, and the satisfying drama of a full-bleed flavour transition.
